# AI-Email-Classification-Auto-Draft-Agent
AI Email Classification & Auto-Draft Generation Agent | n8n + Groq + Gmail

An intelligent email automation workflow built using n8n, Groq LLM, and Gmail. The system automatically monitors incoming emails, classifies them into different categories (Order or Inquiry), and generates professional email draft responses using AI.

The workflow reduces manual email handling, improves response speed, and helps businesses automate customer communication efficiently.

Features:
• Automatic Gmail monitoring
• AI-powered email classification
• Order and Inquiry detection
• Professional email draft generation
• Groq LLM integration
• Gmail Draft automation
• Scalable business communication workflow

Tech Stack:
• n8n
• Groq LLM
• Gmail API
• AI Agent
• Text Classifier

Use Cases:
• Customer Support
• Sales Teams
• Order Management
• Business Email Automation
