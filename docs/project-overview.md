# Project Overview

## AI Email Classification & Auto-Draft Generation Agent

This project automates business email handling using AI.

### Features

- Gmail email monitoring
- AI-powered email classification
- Order and Inquiry detection
- Professional email response generation
- Automated Gmail draft creation

### Technologies Used

- n8n
- Groq LLM
- Gmail API
- AI Agent
- Text Classifier

### Benefits

- Saves time
- Reduces manual work
- Improves response speed
- Maintains professional communication
